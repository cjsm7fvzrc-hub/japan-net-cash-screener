# 日本株ネットキャッシュ・スクリーナー

JPX公式の全上場銘柄一覧を取得し、GitHub Actions上で `yfinance` を分割実行します。結果はSQLite (`data/stocks.db`) に蓄積し、Web画面は書き出されたJSONだけを読みます。ブラウザを閉じても処理は継続します。

## 判定条件

- ネットキャッシュ比率 1.00以上
- PER 10倍以下
- PBR 1倍以下
- 時価総額20億円以上、500億円未満
- 流動資産が負債を上回る

ネットキャッシュ = 流動資産 + 投資有価証券 × 70% − 負債

## GitHubへの設置（パソコン推奨）

1. GitHubで新しい公開リポジトリを作成します。
2. このZIPを展開し、中にあるファイルをすべてリポジトリ直下へアップロードします。
3. リポジトリの `Settings` → `Pages` → `Build and deployment` のSourceを **GitHub Actions** にします。
4. `Actions` → `Update Japanese stock data` → `Run workflow` を実行します。
5. 以後は毎時17分に約200社ずつ自動更新されます。全銘柄を一巡すると次回は先頭から更新します。
6. `Actions` → `Deploy web screen` が完了すると、`Settings` → `Pages` に公開URLが表示されます。

通常、約3,800社なら一巡に約19回かかります。実行遅延を含め、おおむね1日以内で全銘柄がそろう設計です。手動実行時は `batch_size` を変更できますが、対象母集団は常に全上場銘柄であり、画面上の「50社・100社」選択はありません。

## 保存データ

- `data/stocks.db`: 銘柄ごとの最新値を保存するSQLiteデータベース
- `data/results.json`: Web表示用データ
- `data/status.json`: 進捗、最終更新、失敗件数など

## 注意

Yahoo Finance側のアクセス制限や勘定科目差により、一部銘柄は取得に失敗することがあります。失敗数は画面に表示され、次の周回で再取得されます。投資判断前に各社IR資料で確認してください。
